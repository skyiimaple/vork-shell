版本日志

v0.1.0 · 首版候选 · 尚未发布

按实际开发日期，查看万能终端的功能迭代。

2026-10-09

项目管理与连接交互

  • 连接按 SSH、SQLite、MySQL、PostgreSQL、Redis 固定类型自动分组，原自定义分组迁移为项目。
  • 项目可独立创建、重命名、删除，跨类型选择成员，同一连接可以加入多个项目。
  • 连接名称允许完整换行显示，收藏、编辑、复制、项目管理与删除收进下拉菜单。
  • Redis 数据库改为下拉切换，新增不含凭据的当前连接详情。
  • Redis 普通搜索支持包含匹配，空批次继续扫描，分页失败停止自动扫描。
  • 连接图标按类型区分，已连接与当前连接显示高亮；新增关闭连接按钮，断开后保留标签并支持重连。
  • 新增统一设置入口，集中管理主题、版本更新、快捷键、项目主页与五种连接类型的 JSON 配置导入导出。
  • 新增本地操作与错误日志，支持搜索、级别筛选、查看和导出；日志轮转并隐藏凭据与操作内容。
  • 连接类型图标移至分组标题，连接项使用已连接/未连接状态图标；每个连接支持独立设置已连接背景色并持久保存。
2026-10-08

数据管理与首版准备

  • 数据表支持服务端分页、排序、筛选和带冲突检测的单元格编辑。
  • SFTP 新增重命名、删除确认、传输进度和保留 SSH 连接的传输取消。
  • Redis 支持六种类型新建键、集合分页大小切换及 JSON 高亮。
  • 数据库可关联已保存 SSH 配置，自动建立隧道并随数据库连接释放。
  • 支持导入 Another Redis Desktop Manager 的 .ano 与 Redis JSON 配置，预览选择、重复跳过并加密保存密码。
  • 新增版本日志页面、三平台安装配置与手动检查、下载、确认安装更新流程。
  • 修复单击连接与独立编辑的交互，连接失败持续显示提示。
2026-10-06

日常工作流完善

  • 连接支持分组、收藏、排序、复制与手动重连。
  • 恢复工作区标签与 SQL 草稿，支持查询历史、SQL 收藏及脚本多结果。
  • 代码编辑器增加语法高亮和本地 SQL 表、字段自动补全。
  • SSH 独立终端分屏、SFTP 批量传输、Redis 集合编辑及批量 TTL 操作。
