# Vork Shell

一个基于 Electron 的万能终端工作区，把 SSH、SQLite、MySQL、PostgreSQL 和 Redis 放在同一个桌面应用中。

## 开发

需要 Node.js 22.12+（建议 Node 24 LTS）与 pnpm 11。

```sh
pnpm install
pnpm dev
```

首次安装会下载 Electron。若本机曾设置 `ELECTRON_RUN_AS_NODE`，运行桌面命令前取消该变量。

```sh
pnpm lint
pnpm format:check
pnpm typecheck
pnpm test
pnpm build
pnpm start
pnpm test:desktop
pnpm test:enhancements
```

`test:desktop` 在临时用户数据目录中启动真实 Electron，验证 preload 隔离、SQLite 查询、主题切换、查询界面与连接对话框，并把截图保存至被 git 忽略的 `.artifacts/`。

## 基础组件约定

业务界面优先使用 `components/ui` 中的 shadcn-vue 组件，缺少组件时先按需生成；不直接写原生交互控件或调用浏览器 confirm/alert/prompt。Button、Input、Textarea、Select、Checkbox、Label、Dialog、AlertDialog、Popover、Alert、Badge、Tabs 和 Table 已统一。HTML 的布局与表单语义标签可正常使用，生成组件内部的原生元素是组件实现所需。

TanStack Vue Table / Virtual / Query 负责数据模型、虚拟滚动与请求状态；表格显示由 shadcn-vue Table 承担。xterm 负责 SSH 终端显示与输入，CodeMirror 6 负责代码编辑与语法高亮。编辑器使用 [官方扩展接口](https://codemirror.net/examples/basic/)集成，业务按钮及菜单仍使用 shadcn-vue。`pnpm check:ui` 检查业务 Vue 文件中的原生控件，已加入 `pnpm check`。

## 当前功能

- 深色、亮色、跟随系统主题；选择保存在本地，界面与 SSH 终端同步切换。
- 连接配置保存、更新、复制、搜索与删除；分组与拖拽排序、收藏筛选、快速连接和断线手动重连；真实连接测试后立即释放测试会话；多会话标签页，关闭会话释放资源。
- SSH：密码或私钥认证、PTY、终端输入/输出、窗口尺寸同步、主机指纹确认、有界输出与背压；SFTP目录浏览、创建目录、上传与下载，本地回环地址端口转发管理。
- SQLite：选择已有文件，或使用 `:memory:` 试验台；通过工作线程执行查询，保留 NULL、大整数和二进制信息。
- SQL 对象浏览：SQLite main/已附加数据库、MySQL 可见数据库、PostgreSQL 用户 schema选择；字段查看、对象搜索、安全引用名称的 LIMIT 100 预览语句；面板内最近20条成功查询历史、跨连接持久化历史搜索，当前结果 CSV 导出。预览和历史恢复需手动执行。
- MySQL / PostgreSQL：独立连接、可选 TLS、按顺序执行SQL脚本、选中内容执行、多结果集切换、结果表格与执行耗时。
- Redis：SCAN 游标分页、命名空间键树、模式/类型筛选、数据库切换、服务器概览；String / Hash / List / Set / ZSet / Stream 内容预览，TTL 设置与清除、安全重命名、删除、保留 TTL 的字符串编辑，以及命令控制台；Hash成员增改删、List推入/索引编辑/两端弹出、Set增删、ZSet成员增改删，显式确认并检查并发修改。支持 ACL 用户与 TLS。
- SQL/Redis 执行采用 TanStack Vue Query mutation，不自动重试。Table v9 与 Virtual 提供 headless 与虚拟化结果表格。

这是在 MVP 基础上继续增强的开发版本。SSH 已有本地真实 SSH 服务器集成测试，SQLite 已有真实桌面闭环。Redis 已通过本地 Redis 8.10.2 集成和真实 Electron 界面验证；MySQL、PostgreSQL 及远程部署连接需要实际服务进一步验证；仓库不包含服务器凭据。

## 使用

点击「新建连接」，选择类型并填写配置。保存配置时使用系统加密保存密码及私钥口令，再次打开连接自动恢复；旧配置需重新输入并保存一次。SQL编辑器支持执行脚本，结果区默认显示最后一个成功结果，可用结果集选择器切换。连接配置保存到 Electron 的 userData 目录。点击「测试连接」会使用当前表单建立真实连接并立即断开，不打开会话标签；SSH首次测试仍需确认主机指纹。SQLite文件连接会按正常连接流程打开文件，建议用 `:memory:` 测试临时数据库。侧栏的复制按钮会生成新配置草稿，不复制密码或私钥口令；点击保存后才写入。编辑已有配置并点击当前类型不会创建重复配置。

点击「体验 SQLite」可以直接创建临时内存数据库，然后运行默认查询，无需安装数据库服务器。打开已有 SQLite 文件后，写入操作会修改该文件；应用不会自动执行编辑器里的命令。

- `Cmd/Ctrl + N`：新建连接。
- `Cmd/Ctrl + Enter`：执行 SQL/Redis 命令。
- `Cmd/Ctrl + W`：关闭当前会话。
- SQL 编辑器输入时出现补全；`Ctrl + Space` 手动唤起，方向键选择，`Tab`/`Enter`接受，`Esc`关闭。接受补全不会执行SQL。
- 表名补全需刷新对象浏览器，字段补全需点击表读取字段；切换数据库/schema会清空旧结构。当前补全完全在本地运行，不接入AI、不发送SQL、结构或查询结果。

## 当前边界

- SQL 和 Redis 命令编辑器采用 CodeMirror 6，支持 SQL 方言高亮、Redis命令/字符串/数字高亮、行号、括号匹配、撤销/重做与深浅主题；SQL 本地自动补全支持方言关键字、当前范围已加载表名、已查看表的字段，以及 SQL 扩展支持的别名上下文。数据表管理支持限定字段的单元格编辑，任意SQL结果仍只读；跨PostgreSQL数据库需新建连接。
- 单次展示最多 1000 行或 4 MB。SQLite 在达到上限后停止迭代；远程 SQL 驱动流式消费并限制保留结果，但不自动改写 SQL 或替用户追加 LIMIT。大查询建议显式使用 LIMIT。
- 查询等待超时为 30 秒。停止操作会断开整个会话，不保证已提交的服务器端写入回滚；需要重新连接。
- Redis 订阅与阻塞命令暂不支持，可通过 SSH 使用 redis-cli。避免用 KEYS 或巨大的聚合命令读取整库，按需使用 SCAN。控制台不支持更改认证、协议、事务或数据库状态的命令；数据库通过工具栏切换。
- SSH 首次连接显示指纹，需核对后信任；后续密钥变化会再次要求确认。
- 当前验证的是开发与构建后的 Electron 应用，不包含可分发安装包、代码签名或自动更新配置。
- 浏览器单独预览仅展示界面；真实连接能力来自 Electron preload。

Redis 工作区参考 [skyiimaple/redis-desktop](https://github.com/skyiimaple/redis-desktop) 的浏览与类型预览思路，驱动仍运行在 Electron 主进程。字符串预览上限 64 KiB，超限或二进制值不可通过文本编辑保存；保存会检查原值防止覆盖其他客户端修改。键浏览最多加载约 10000 个键，需缩小模式继续；SCAN 的 COUNT 是提示，完整返回批次不会被切掉。非 UTF-8 键名会明确报错，避免解码后操作错误键。

提供本机 redis-server 路径，可运行隔离的真实 Redis 测试；脚本启动临时服务器与临时目录，不使用已有数据库：

```sh
VORK_REDIS_SERVER=/absolute/path/to/redis-server pnpm test
VORK_REDIS_SERVER=/absolute/path/to/redis-server pnpm test:desktop
```

## 文件与隧道使用

打开 SSH 会话后，通过「终端 / SFTP 文件 / SSH 隧道」切换。SFTP 使用同一认证连接；点击读取目录后可打开子目录、创建目录、上传或下载普通文件。文件选择与保存由主进程系统对话框完成，renderer 不接收任意本地文件读写接口。

- 单文件上限100 MiB；文件传输120秒超时会断开SSH，目录及隧道请求30秒超时。目录最多展示2000项。支持最多100个普通文件批量上传/下载；暂不支持断点续传、目录递归传输或远端删除。
- 下载先写本地临时文件，完成后发布到用户选定路径。上传先写同目录唯一 `.vork-UUID.part`，完成后用普通 [SFTP v3 rename](https://datatracker.ietf.org/doc/html/draft-ietf-secsh-filexfer-00#section-6.5) 发布，不使用覆盖目标的 OpenSSH POSIX 扩展。目标已存在或并发创建时拒绝覆盖；断连可能残留 `.part` 临时文件，错误消息包含路径，需重新连接后清理。
- 隧道只监听127.0.0.1；本地端口0自动分配。目标主机从SSH服务器侧访问，在数据库表单使用显示的本地端口。每会话最多4条隧道，关闭隧道/会话会释放监听和活动连接。
- Redis集合中的非UTF8成员仅作HEX预览，该批编辑禁用；Stream高级写入继续通过命令控制台。List弹出需要对应端的条目在当前页。
- CSV仅导出当前有界结果；截断结果不会补读。CSV将NULL输出为空字段，对公式形式的内容加前置单引号，适合电子表格查看。面板最近历史保留20条；全局历史在 userData 的 query-history.json 保存最近500条成功 SQL（每条最多64 KiB），包含连接标识和 SQL 原文，不包含连接密码。恢复仅填入编辑器，需手动执行。

`pnpm test` 包含真实SSH/SFTP协议测试（隔离内存远端文件与本机临时文件）；`test:desktop` 验证SFTP上传下载和隧道界面。测试文件选择器返回专用临时路径，正式应用仍使用系统选择器。SQL/Redis/SSH/SFTP的真实桌面截图位于`.artifacts/`。MySQL、PostgreSQL仍需要实际远端服务联调。

## 工程结构

```text
src/main/           窗口、IPC、配置存储、连接生命周期与 Node 驱动
src/preload/        sandbox 中的最小业务桥接
src/shared/         可序列化连接、会话和结果契约
src/renderer/src/   Vue 工作区、shadcn-vue 组件、主题、终端与查询面板
tests/              查询、验证、存储、生命周期与 SSH 集成测试
scripts/smoke.cjs   真实 Electron 桌面验收
```

核心版本在 package.json 和 pnpm-lock.yaml 中固定。Vite 采用用户授权的 7.3.6，匹配 electron-vite 5.0.0。TypeScript 采用 6.0.3：最新 TypeScript 7 的 API 与当前 vue-tsc / Vue 组件类型解析尚不兼容。其他核心依赖按 2026-10-05 的 npm latest 核验。

表与视图列表：单击查看字段；双击直接查询前 1000 行。右键菜单支持查看数据、查看字段、查询总行数、生成 SELECT、复制表名、复制完整表名和刷新列表。生成 SELECT 仅填入编辑器，查看数据与总行数直接执行。

## MVP 后续增强

- 连接：拖动侧栏连接可排序；拖到其他文件夹的连接上同时移动文件夹。顺序与文件夹写入保存配置；编辑连接时填写「文件夹」名称，留空表示未分组。分组可折叠，旧配置无需迁移。
- 标签：右键提供关闭、关闭其他、关闭所有与复制标签。复制使用独立数据库/SSH连接；内存 SQLite 会创建独立空数据库。关闭标签释放对应会话及分屏/隧道。
- 查询结果：点击表头在升序、降序、原始顺序之间切换；拖动表头右侧边缘调整列宽，边缘按钮也支持左右方向键。排序仅作用于当前有界结果，不重新查询服务器。
- SQL：点击「格式化 SQL」整理换行与缩进，保留原始关键字大小写、字面量、参数与注释；格式化不会执行查询。查询工具栏保留当前面板历史，顶部「查询历史」跨连接搜索所有已保存的成功 SQL。
- SSH：终端工具栏支持水平/垂直分屏，每个认证连接最多4个独立PTY；点击面板聚焦输入，关闭分屏只释放该PTY。面板出错后可重新加载，重载释放旧子PTY并恢复默认终端和隧道列表。
- SFTP：上传系统对话框可多选文件，远端列表复选普通文件后批量下载到选定目录。每批最多100个文件，串行传输、逐文件报告成功/失败；批量上传不覆盖远端目标，批量下载不覆盖本地目标。
- Redis：勾选键后批量读取TTL（-1永久、-2不存在），确认后批量设置秒数或清除过期时间。每批最多100个键，固定数据库与键快照，逐键报告结果；切换数据库或筛选清空旧选择。
- 工程：会话面板错误边界提供重载，其他面板继续工作；应用通知支持并发显示、单条关闭和自动消失。退出时保存窗口正常大小/位置与最大化状态，显示器变化时将窗口移回可见区域。
- 快捷键：顶部「快捷键」可修改新建连接、关闭会话、执行查询/命令、全局历史搜索；保存时校验格式与冲突，设置即时生效并持久化。默认历史搜索为 `Cmd/Ctrl + Shift + F`。

### SQLite 便捷命令

在 SQL 编辑器输入后点击执行：

```text
.import my_table
.import "table with spaces"
.dump
.dump my_table
```

`.import` 使用系统对话框选择UTF-8 CSV。CSV第一行为目标现有普通表的字段名，允许字段重新排序或只导入部分字段；空字段作为空字符串写入。支持逗号、双引号、字段内换行与CRLF，整批在事务/savepoint中执行，任何行失败全部回滚。

`.dump` 使用保存对话框输出SQL，包含 main 的普通表结构、可写字段数据、索引、视图、触发器和自增序列。保留NULL、BLOB、大整数与文本；不支持虚拟表/shadow内部表。完整导出遇到临时对象或附加数据库会明确拒绝，请指定main中的普通表。CSV/SQL均上限16 MiB，CSV最多100000条数据行；大库请用原生 sqlite3 工具。

## 日常连接与工作区

- 侧栏按文件夹分组，支持拖拽移动；星号收藏在组内优先显示，可切换仅显示收藏。单击连接条目使用已保存配置直接连接，右侧铅笔按钮单独编辑；连接时显示加载状态，失败原因显示在通知中并保留到手动关闭。
- 断线标签的「重新连接」会使用本次运行的连接快照，替换原标签并保留SQL草稿；不会自动重连。快照仅在主进程内存保留最近32项，窗口关闭清除。
- 工作区在本地保存标签顺序、当前标签与SQL草稿。启动后恢复为「待重连」，不会自动连接或执行SQL，不恢复结果表格、远端目录、SSH输出、数据库事务状态或内存SQLite数据。保存配置的连接需点击重连；未保存的非SQLite连接需重新填写参数。
- 工作区不保存密码/口令，只引用已保存连接ID；凭据仍由既有系统加密配置存储处理。草稿本身可能含SQL敏感文字，保存在Electron本地存储。最多恢复前20个标签，每份草稿前64 KiB；超限会提示退出前备份。

## SQL脚本与选中执行

编辑器有非空选区时，工具栏显示「执行选中」，执行按钮及自定义执行快捷键优先执行选区；没有选区时执行全文。接受补全、恢复草稿或历史都不会执行SQL。

脚本先完成词法拆分与边界检查，再在同一连接顺序执行，每条语句保留结果。首个失败会停止后续语句，失败之前的结果仍可查看。应用不会自动开启事务或回滚已完成的写入；需要事务时显式写BEGIN/COMMIT/ROLLBACK，失败后自行确认事务状态或断开连接。批次超时/停止会断开连接。

- 支持引号内分号、标识符、注释、PostgreSQL美元引号函数体、SQLite触发器语句块。MySQL DELIMITER/存储程序、可执行注释和PostgreSQL BEGIN ATOMIC暂不支持此脚本拆分流程。采用MySQL默认反斜杠转义和PostgreSQL标准字符串规则；变更对应会话SQL模式后需单独执行并核对语句。
- 每批最多100条、1 MiB SQL、30秒；单个结果仍最多1000行/4 MB，累计展示最多16 MiB。累计达到上限时截断当前结果并停止后续语句；提示会明确当前语句已经执行。
- CSV/复制仅作用于当前选中的结果集；存储过程CALL返回的多个内部结果仍遵循原驱动行为，尚未提供独立结果集映射。

`pnpm test:workflows`使用隔离用户数据与SQLite文件，验证收藏、快速连接、选中SQL、多结果集、失败停止、刷新后未连接恢复、草稿保留、手动重连和资源释放；截图位于`.artifacts/sql-multi-results.png`。

`pnpm test:connections` 验证单击连接、独立编辑、配置错误提示和连接失败通知。桌面测试窗口在副屏显示且不抢焦点；没有副屏时保持隐藏。

## SQL 收藏片段

SQL 编辑器工具栏的「SQL 收藏」可保存选中的 SQL（没有选择时保存整个编辑器），按名称、SQL或方言搜索，重命名和确认删除。片段跨连接复用，载入替换当前编辑器内容，由用户手动执行；方言不同会标注。离线恢复标签也能管理片段。

片段保存在本机 localStorage，不发送到模型服务；最多100条、每条 SQL 64 KiB、总大小1 MiB。存储损坏时显示错误并保留原始数据。`pnpm test:snippets` 在隔离数据库和副屏验证保存、重命名、载入不执行、重启持久化、删除和损坏数据保护。

## 数据表管理（第4项）

表与视图列表右侧的「管理数据」按钮或右键「管理数据（分页与编辑）」打开数据浏览器。每页20/50/100行，点击表头在服务器升序、降序、默认主键排序间切换；支持单列等于、包含文本、NULL和非NULL筛选。筛选值绑定参数，包含文本按字面匹配百分号、下划线。读取字节截断时停止翻页并提示缩小范围，避免遗漏行。分页是实时读取，不是全表快照。

可编辑单元格带铅笔按钮，打开后核对原值、新值及类型，点击「确认写入数据库」。后台按主键和原值定位，原值变化或行已删除时拒绝写入，不自动重试；成功后刷新当前页。沿用连接当前事务，不隐式提交。任意SQL查询结果仍只读。

主键、生成字段、二进制和复杂类型只读；无可靠主键、视图、SQLite虚拟表/实际BLOB主键、PostgreSQL传统继承父表不提供编辑。编辑快照保留本次连接最近2页、有效5分钟、每页最多1 MiB，写入后失效。

`pnpm test:table-data` 在隔离SQLite数据库和副屏验证分页、排序、筛选、写入和并发冲突。MySQL/PostgreSQL已有绑定参数与SQL生成测试；真实服务测试分别由 `VORK_MYSQL_PORT` 和 `VORK_POSTGRES_PORT` 启用，使用专用 `vork_test` 数据库和 `vork` 测试账号，密码变量为对应 `VORK_MYSQL_PASSWORD` / `VORK_POSTGRES_PASSWORD`。本次未配置远端服务，相关集成测试跳过。

后续顺序记录在 [4–8实施计划](docs/superpowers/plans/2026-10-08-roadmap-4-8.md)：第4–6项已完成，随后推进隧道关联数据库 → 安装包及更新。

### SFTP 与 Redis 增强（第5、6项）

- SFTP 文件行提供独立重命名、删除按钮。重命名拒绝覆盖目标；删除需要确认，目录仅删除空目录，符号链接删除链接本身。操作成功后刷新当前目录。
- 上传/下载显示当前文件、已读取字节、总字节和进度条。取消传输保留 SSH 终端与隧道；未完成的文件通过临时文件隔离并清理。批量取消停止后续文件，已经完成的文件保留。最终提交文件时取消按钮禁用；超时或断连仍可能残留远端临时文件，错误会给出路径。
- Redis 工具栏「新建键」支持 String、Hash、List、Set、ZSet、Stream，集合必须提供一个初始成员；可设置 TTL。后台一次 Lua 操作检查同名键并创建，TTL 权限在创建前预检，失败不会因缺少 EXPIRE 权限残留永久键。
- 集合每批可选择50/200/500项，上一批/下一批带加载保护，刷新或成员修改后回到首批。Hash/Set 的 SCAN COUNT 是提示，可能返回更多项；实时集合变动可能导致重复或位置变化，分页不代表快照。
- 字符串的 JSON 模式采用只读 CodeMirror 高亮，支持深浅主题。原始文本仍可复制或编辑；无效 JSON 显示提示，二进制或超限字符串保持原有只读边界。

`test:desktop` 使用隔离 Redis 和 SSH/SFTP 服务，在副屏验证新建键、JSON高亮、集合翻页、文件重命名/删除确认、传输进度及取消后继续使用会话；没有副屏时测试窗口保持隐藏。

## SSH 隧道、版本日志与发布（第7、8项）

MySQL、PostgreSQL、Redis 连接表单的「数据库 SSH 隧道」可选择已保存的 SSH 配置。数据库地址填写从 SSH 服务器访问的目标地址，应用自动建立独立隧道；断开数据库、连接失败或关闭窗口都会释放隧道。重连重新读取保存的 SSH 配置，沿用主机指纹验证与凭据加密。SSH 终端标签无需保持开启。MySQL 隧道启用 TLS 时需使用证书中的 DNS 主机名，IP 配置会明确拒绝。

顶部「版本日志」和底部版本号可打开可搜索的时间线，包含 2026-10-05、06、08 的实际开发记录。`release-history.json` 是日志唯一来源，`pnpm release:notes` 生成 CHANGELOG 和离线 HTML。当前 `0.1.0` 标记为首版候选。

`pnpm package:mac` 生成内部验收用未签名 DMG / ZIP；开发和未启用构建关闭在线更新。正式构建提供手动检查、下载、安装和错误提示，需发行签名、公证和发布渠道验收。三平台 CI 只保存构建产物，不自动发布。完整步骤、凭据要求和验收边界见 [发布指南](docs/RELEASE.md)。

`pnpm test:release` 在隔离用户数据和副屏验证日志搜索、更新禁用状态、SSH 配置选择、测试连接、Redis 隧道与断开；`node scripts/package-smoke.cjs` 验证实际 macOS ARM64 安装包启动、SQLite 工作线程和隔离配置，全程隐藏窗口。

## 导入 Redis 连接配置

连接资源标题右侧的「导入连接配置」按钮支持 Another Redis Desktop Manager 导出的 `.ano`（Base64 JSON）和 Redis JSON 连接数组，也接受 `{ "connections": [...] }` 包装格式。选择文件后预览名称、地址、含密码标记及状态，勾选需要的条目再点击「确认导入」。不自动连接服务器，不覆盖已有连接。

按主机、端口、用户名、数据库、TLS 和隧道关联识别重复；同一文件与已有配置中的重复连接会跳过。密码只在主进程内保留，确认后通过系统凭据加密写入，系统加密不可用会拒绝含密码的导入。文件最多 2 MiB、500 条；预览10分钟后失效。

当前支持普通 Redis 连接与系统信任的 TLS，映射 `host`、`port`、`name`、`username`、`auth`/`password`、`database`/`db`。Cluster、Sentinel、只读策略、自定义 TLS 证书/SNI、内嵌 SSH 配置会标注为不支持，不会悄悄退化为直连；SSH 需先在应用创建配置并关联 Redis。外部连接 ID、排序、文件夹和键分隔符等展示设置不迁移。加密导出文件不支持。

`pnpm test:import` 使用隔离用户配置与假凭据，在副屏验证预览、取消、批量加密保存、侧栏刷新、重复跳过、不支持条目及错误提示；不连接任何服务器。用户提供的导出文件不进入仓库或测试夹具。

## 类型分组与项目

连接按 SSH、SQLite、MySQL、PostgreSQL、Redis 五个固定类型分组，空组也保留。项目是独立的连接集合，侧栏下拉选择项目后，项目内仍按类型展示。一个连接可同时加入多个项目；项目关系不改变连接配置或类型。

侧栏「管理项目」入口创建、重命名、删除项目，并勾选跨类型成员；连接行「…」里的「管理所属项目」可为单个连接选择多个项目。删除项目保留全部连接；删除连接后，项目展示会过滤已不存在的引用。同类型连接可以拖拽排序，跨类型拖拽不改变分组。旧自定义文件夹在首次打开项目功能时迁移为同名项目，迁移一次，不改凭据或类型。

项目仅保存 ID、名称和连接 ID，原子写入本机 `projects.json`，不保存密码。最多100个项目，项目名称1–100字且不区分大小写重复。配置文件损坏会报错并保留原文件。`pnpm test:projects` 在隔离用户数据和副屏验证旧文件夹迁移、跨类型创建、重命名、筛选及删除保留连接。

## 设置与本地日志

顶部「设置」集中提供主题、版本更新与迭代日志、快捷键、项目主页、连接配置导入导出及操作日志。JSON 导出覆盖 SSH、SQLite、MySQL、PostgreSQL、Redis，保留隧道关联，不导出密码、私钥路径及口令；导入后需要补充凭据。若连接关联 SSH 隧道，导入时需同时选择关联 SSH 连接；已存在的 SSH 配置可以复用。原有 .ano 和 Redis JSON 导入继续可用。

日志位于应用 userData 下的 `logs/activity.jsonl`，macOS 默认 `~/Library/Application Support/vork-shell/logs/activity.jsonl`。记录连接、断开、重连、配置变更、查询/命令执行、Redis/SFTP 修改及错误；不保存 SQL、终端输入、Redis 值、查询结果或密码/密钥。界面显示最近 2000 条，可按关键字和级别筛选，导出 JSON Lines 包含当前与上一份保留文件。单文件约 5 MiB 后轮转，最多保留两份。尚未启用在线更新的候选版本会明确提示从发布渠道下载。

## MongoDB 工作区

新建连接选择 MongoDB，填写主机与端口（默认 27017）。未启用认证的服务器可留空用户名和密码；启用认证时填写账号、密码和认证数据库（authSource，默认 admin），可另外指定初始数据库。密码沿用系统加密保存，配置导出不包含密码。TLS 使用驱动默认的服务器证书校验。

连接后从左侧选择数据库和集合，也可直接输入有权限访问的数据库名称。文档页支持 JSON / Extended JSON 查询条件和排序，每页 50 条；空排序默认按 `_id` 升序。ObjectId 查询示例：`{"_id":{"$oid":"507f1f77bcf86cd799439011"}}`。索引页展示索引定义。

可新增、编辑和删除单个文档。编辑须保留 `_id` 和 Extended JSON 类型；保存或删除时按主进程保留的原文档快照校验，若其他客户端修改或删除过该文档会拒绝操作，需重新查询。查询响应最多 4 MiB；输入文档最多 1 MiB，大文档仅供查看。集合列表最多 2000 项，数据库列表最多 2000 项；操作限时 25 秒。视图按 MongoDB 权限和写入限制返回错误。

首版支持主机／端口连接，不支持 `mongodb+srv` 地址、SSH 隧道、mongosh 脚本、聚合管道或索引修改。支持普通 JSON 和 MongoDB Extended JSON，查询不允许服务器端 JavaScript。

在专用测试 MongoDB 实例上运行（测试会创建并清理随机名称的测试数据库）：

```bash
VORK_MONGODB_TEST_PORT=27017 pnpm exec vitest run tests/mongodb.test.ts tests/mongodb.integration.test.ts
VORK_MONGODB_TEST_PORT=27017 pnpm test:mongodb
```
