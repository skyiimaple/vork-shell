# 结果表格

查询结果和「管理数据」共用表格组件。表头支持排序，列边缘可拖动调整宽度，也可聚焦列宽按钮后按左右方向键调整。

点击右上角「列」打开显示设置，可搜索列名、逐列隐藏或显示，并恢复全部列。列按原始位置区分，同名列可以分别设置，至少保留一列。设置只在当前组件会话中保留；结果列名或顺序改变后重置。隐藏不影响整表复制和导出，它们仍使用当前结果的全部列。

悬停单元格后点击查看图标，或双击单元格，打开只读详情。详情显示字段、原始行号、值类型和字符数量，并展示完整返回值；「复制原值」使用桌面剪贴板，NULL 复制为文本 `NULL`。文本内容按原样保留，不解析或重写 JSON 中的大整数。这里的完整值限于数据库已返回的数据，不恢复查询本身被截断的内容。

数据浏览中的铅笔按钮仍用于编辑，查看按钮不执行写入。关闭详情后可继续原来的选行、分页或编辑操作。重新读取结果会关闭旧单元格详情，避免把旧值当成新查询的数据。

`pnpm test:result-export` 验证列隐藏、最后一列保护、原值查看/复制、隐藏列仍参与导出，以及五种复制格式。`pnpm test:table-data` 验证共用组件的数据库分页、排序、筛选、编辑与行操作。
