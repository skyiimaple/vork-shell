# SQLite 已有字段编辑

在「查看结构 → 字段」选择类型、默认值或可空。SQLite 使用重建表执行这三类修改，先展示步骤预览，确认后运行；预览本身不改表。它包含运行时读取的校验和序列维护，不能作为独立迁移脚本复制执行。

执行时取得 `BEGIN IMMEDIATE` 写锁，重新核对结构，创建新表并复制现有数据，再校验行数及未授权变化，替换原表、恢复普通索引和触发器，检查外键后提交。NOT NULL、唯一约束、外键或对象恢复失败都会回滚。恢复对象时保留原视图引用；复制阶段不触发原表的业务触发器。自引用和传入外键不会因替换原表发生级联删除。

默认值修改不重写已有值。未勾选转换时，复制导致值或存储类型变化会被拒绝；类型修改可显式选择 CAST，允许修改目标字段及其生成结果。未编辑字段仍校验原值和存储类型。BLOB、大整数、可访问的隐藏 rowid、自增序列高水位，以及 WITHOUT ROWID、STRICT、原有约束都需保留。自增计数不因表为空或原最大行已删除而退回。

连接中已有事务时不能执行重建，请先自行提交或回滚；拒绝操作不会回滚用户事务。工具临时关闭外键执行、启用兼容重命名模式，并在成功或失败后恢复原连接设置。提交检查中仍存在的外键问题、过期预览和结构变更会阻止执行。预览有效期5分钟，令牌只能执行一次，普通数据变化不会使预览过期，确认时复制写锁内的数据。

当前支持 main 和附加数据库中的普通表。虚拟表及其影子存储不会按普通表重建。临时表、存在临时触发器的表、修改生成字段类型、从其他主键类型改为 INTEGER rowid 别名，以及全部 rowid 名称被字段遮蔽的情况暂不开放。目录和字段仍受现有读取上限约束，超过上限会拒绝执行。复杂约束编辑和这些特殊情况仍需继续补齐，大表和强制中断的恢复验收也尚未完成。

`tests/sqlite-rebuild.test.ts` 验证完整数据/对象保留、附加数据库、命名约束、生成字段、空表自增计数、外键、未授权转换拒绝，以及替换原表后失败的回滚和约束自动回滚。`pnpm test:schema-tools` 通过真实 Electron worker、IPC 和桌面入口验证默认值、可空、类型转换、错误回滚、依赖对象保留，并检查长 SQL 预览中的确认按钮始终可见、可实际点击。

外键创建和删除也复用此路径，可删除具名或未命名内联外键；详见 [外键管理](FOREIGN-KEYS.md)。删除错误外键后若完整检查通过，可以保留原数据完成修复。
