# MVP 后续增强（已获用户批准）

沿用 Electron/Vue 与现有 IPC 所有权检查，业务控件优先 shadcn-vue。每个功能点运行 pnpm typecheck、pnpm test。用户要求直接实现，无需重复确认。

1. 工程基础：每个会话面板独立错误边界、可关闭 Toast 队列、屏幕可见范围内恢复窗口正常 bounds 和最大化状态、可持久化且冲突校验的快捷键设置。
2. 连接管理：持久化拖拽顺序、一级文件夹分组（旧配置默认未分组）、标签菜单关闭其他/全部与独立连接复制。复制 SQLite 内存连接创建独立数据库。
3. SQL：结果列宽拖拽，表头升序/降序/无排序；格式化保留字面量和注释；持久化带连接标识的成功查询历史，跨连接搜索与手动恢复执行。
4. SSH：同一认证连接多个独立 PTY，水平/垂直分屏、关闭分屏释放 channel；SFTP 系统对话框多选上传、选中远端文件下载到目录，逐文件结果，不覆盖远端文件。
5. Redis：选中多个键批量读 TTL、设置秒数或持久化，确认批量修改，逐项结果和刷新。
6. SQLite：.import 通过系统对话框选择 CSV，指定现有表，参数绑定与事务回滚；.dump 通过系统对话框导出 SQL，包含结构和数据、保留 blob/NULL/整数，支持普通用户表，拒绝不支持的对象而非静默丢弃。

保存窗口状态和查询历史不包含连接凭据。历史最多500条/每条64KiB。仅恢复编辑内容，不自动执行。测试环境受沙箱端口权限影响时记录实际结果，不隐藏失败。
