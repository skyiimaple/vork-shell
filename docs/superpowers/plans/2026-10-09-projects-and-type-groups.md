# 固定类型分组与独立项目

类型分组固定为 SSH、SQLite、MySQL、PostgreSQL、Redis，空组仍保留。项目通过连接ID引用跨类型连接，默认允许一个连接出现在多个项目。项目删除不删除连接，连接编辑不改变成员关系；连接删除后清理无效引用。旧自定义group首次迁移为项目，不改连接类型或凭据。

实施：

1. 类型分组纯函数与测试；侧栏不再使用group，不再跨类型拖拽改变分组；去掉配置表单手动分组。
2. ProjectStore 原子持久化、迁移、名字校验、重复与并发测试；可信IPC/preload/API。
3. 项目筛选、创建/重命名/删除、跨类型勾选成员管理，所有基础控件shadcn；显示全部仍按固定类型组织。
4. 单元、类型、格式、UI审计、构建及副屏隔离数据验收；独立复查；文档更新。

不自动连接、不修改用户服务器；不提交源码或发布安装包。
