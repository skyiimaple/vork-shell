# 数据筛选

从表的「管理数据」打开数据浏览。选择字段、操作和值后，可以直接「应用筛选」，或先「添加条件」继续设置其他字段。支持等于、不等于、大小比较、包含、不包含、开头/结尾匹配，以及 NULL/非 NULL。最多20条条件，通过「全部满足」或「任一满足」组合。

添加的条件显示在工具栏下方，可逐条移除；编辑条件、移除条件和切换组合方式后，点击「应用筛选」才会重新读取。未添加的当前输入也会参与本次应用。「清空筛选」立即清除全部条件并读取第一页。排序、翻页、刷新及写入后刷新沿用已应用条件，不沿用尚未应用的草稿。

筛选在数据库执行，字段名通过元数据验证，值通过绑定参数传递。文本匹配中的 `%`、`_` 和 `!` 按字面量处理；大小写和排序遵循数据库自身规则。不包含和不等于不会包含 NULL 行，需要查找 NULL 时使用空值条件。输入框以文本传值，比较时数据库按字段类型转换；无效转换会显示数据库错误，不会执行额外 SQL。

测试覆盖 SQLite/MySQL/PostgreSQL 的比较和 AND/OR 组合；`pnpm test:table-data` 验证桌面上的多条件筛选、分页、排序和写入后的重新读取。
