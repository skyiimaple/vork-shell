# 结构对比

在 SQL 对象树点击「查看结构」，再点击「结构对比」。支持 SQLite、MySQL 和 PostgreSQL，可以分别选择已连接会话或已保存连接，并填写两侧数据库/Schema。SQLite 使用 `main`，PostgreSQL 通常使用 `public`。

表名范围每行一个，留空读取整个 Schema，最多500张表。对比报告包含两侧独有对象，以及字段类型、顺序、默认值、生成表达式、主键、索引、外键、检查约束、触发器和原始定义差异。可按对象、差异类型搜索筛选，点击条目查看两侧元数据，导出 JSON 保留完整报告。

对比只读取结构，不读取业务行，也不生成或执行同步 SQL。两侧按顺序读取，不构成跨库一致性事务快照；类型、默认值和定义按原文比较，格式、命名或 Schema 限定符可能产生差异。跨方言不推断语义等价。SQLite 检查约束和生成表达式保留在建表原文中，不独立解析。

每侧结构快照上限4 MiB，任务上限5分钟。点击取消后等待当前元数据请求结束再停止；使用已保存连接时创建的临时会话会在成功、失败或取消后释放，不加入最近连接。报告仅属于发起窗口，导出由主进程校验报告编号；连接凭据不包含在报告中。

`pnpm test:structure-compare` 使用临时 SQLite 文件和用户目录验证会话/保存连接选择、字段及索引差异、临时连接释放、JSON 文件和业务数据未被改写。`tests/structure-compare.test.ts` 还验证索引排序规则差异、取消与窗口隔离；真实 MySQL/PostgreSQL 测试通过 `VORK_MYSQL_PORT`、`VORK_POSTGRES_PORT` 指定专用测试库端口，验证完整类型、生成列、检查约束和并发写入后的索引预览。
