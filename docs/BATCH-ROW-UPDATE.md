# 批量更新字段

在「管理数据」中勾选当前页多行，点击「批量更新」，选择一个可编辑字段，填写文本、数字、布尔值或 NULL。先预览 SQL 和绑定参数，再点击「确认执行更新」。只更新所选行的指定字段，不修改主键或生成字段。

每次最多100行、10000个原行匹配参数。服务器使用当前页快照校验每行的全部原值，合并为一条参数化 UPDATE；已被其他客户端修改或删除的行不再匹配。完成后显示实际影响数量与选择数量，例如「已更新 1 / 2 行」，刷新当前页并清空选择。重复设置相同值按驱动返回的匹配行数量报告，不表示该值实际发生了变化。

预览不写入；更换字段、类型或值会使界面中的预览失效，必须重新预览。令牌只能执行一次，有效期5分钟，提交前重新检查表结构。操作沿用当前连接事务，外键和触发器仍可能影响其他数据。

此入口当前对具备可定位标量主键、全部字段可安全比较的普通表开放，复杂字段表及多字段同时批量赋值仍需后续补齐。选择只属于当前页，不跨查询或翻页累积。

SQLite 单元测试验证主键保护、NULL、预览不写入和并发修改跳过；MySQL/PostgreSQL 集成测试验证文本、NULL 及相同值更新的影响数量。`pnpm test:table-data` 验证桌面字段选择、类型输入、SQL 预览、部分更新提示和选择清空。
