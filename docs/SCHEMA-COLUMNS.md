# 字段结构编辑

在表的「查看结构」中选择「字段」。普通表及 PostgreSQL 分区表可以新增字段、重命名字段或删除字段，原始字段元数据也可在下方表格查看。

新增字段支持内置类型、长度/精度、是否允许 NULL，以及文本、数字、布尔、NULL、当前日期/时间/时间戳默认值。类型输入使用受控语法，不接受任意 SQL 片段；枚举、自定义类型和生成表达式尚未加入表单。默认值的合法性及向已有行填充的限制由数据库检查，例如 SQLite 在非空表增加某些动态默认值会被拒绝。

每个操作都先预览实际 DDL 或重建步骤，再确认执行。预览有效期5分钟、一次性使用，提交前重新核对字段、索引、外键、约束及触发器元数据；结构变化会要求重新预览。MySQL 文本默认值按会话 SQL 模式转义，模式变化也会使预览失效。TEXT/BLOB/JSON 默认表达式依赖 MySQL 8.0.13 及以上的原生能力；旧版本不支持的 DDL 会显示数据库错误。

删除会永久移除字段数据，数据库可能自动调整本表依赖索引或约束。删除操作不使用 CASCADE，也不自动重建表来绕过依赖限制，不能删除最后一列。涉及外键、视图、主键或触发器的操作可能被数据库拒绝。操作可能锁表，且沿用当前连接事务；MySQL DDL 可能隐式提交。

MySQL/PostgreSQL 的字段行提供「类型」「默认值」「可空」。类型使用同样的受控语法，PostgreSQL 可勾选显式转换以生成 `USING 字段::目标类型`；转换可能改变已有值，数据库不能完成转换时会报错。默认值支持设置或移除，不重写已有数据。设置 NOT NULL 前，现有数据和默认值都必须满足约束；例如 MySQL 的默认 NULL 可能需要先移除。

MySQL 类型和可空修改复用数据库返回的完整字段定义，保留未编辑的默认值、注释、字符集/排序规则、自增及其他属性。解析无法可靠匹配时会拒绝预览。为防止宽松模式静默截断或替换 NULL，这两类操作临时加入 `STRICT_ALL_TABLES`；预览包含启用严格模式、实际 ALTER 和恢复原模式三步。成功或 DDL 失败后都会恢复；无法恢复时会明确要求重新连接并核对执行结果。只调整当前会话，不修改服务器全局配置。

SQLite 已有字段的类型、默认值及可空修改已接入事务性重建，包含数据、索引、触发器、视图、外键和自增序列检查；详见 [SQLite 重建表说明](SQLITE-REBUILD.md)。临时对象、部分主键别名修改和复杂约束编辑等仍需补齐，不将这些字段操作视为整个结构编辑目标完成。

`pnpm test:schema-tools` 验证 SQLite 桌面新增/默认值/重命名/删除及取消，保留既有索引管理验证。`tests/schema-tools.test.ts` 验证 SQLite 实际 DDL 和类型注入拒绝；`tests/schema-columns.integration.test.ts` 通过专用测试库端口开启 MySQL/PostgreSQL 实测，覆盖转义、MySQL SQL 模式、时间默认值和结构变更冲突。

`pnpm test:schema-column-edit` 使用 `vork-test-mysql-1009` 和 `vork-test-postgres-1009` 两个专用 Docker 测试服务，创建临时表和用户目录，验证桌面类型/可空/默认值设置与移除、PostgreSQL 显式转换及 MySQL 属性保留。结束时删除本次随机命名的表。集成测试另外验证宽松模式下拒绝截断、NULL 约束错误，以及成功/失败后原 SQL 模式恢复。解析器测试位于 `tests/mysql-column.test.ts`。

外键页已提供字段映射、规则选择、创建/删除预览及执行；详见 [外键管理](FOREIGN-KEYS.md)。CHECK、主键等其他约束编辑仍未补齐。
