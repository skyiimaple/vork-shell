# 批量删行

在「管理数据」中，行号旁的复选框可选择当前页多行，表头复选框选择或清空当前页。点击「批量删除」后，先预览 SQL 和绑定参数，再确认执行。最多选择100行，且只对可安全定位的普通表开放；视图、没有标量主键或包含复杂字段的表不开放此操作。

服务器保存原始行快照，按每行主键及所有字段原值匹配，使用一条参数化 DELETE 合并所选条件。快照和预览有效期5分钟，预览令牌只能执行一次，执行前重新检查字段结构。参数最多10000个，超过时需要减少选择行数。

其他客户端修改过或删除的行不再匹配。完成后提示实际删除数量与选择数量，例如「已删除 1 / 2 行」，并刷新当前页、清空选择。部分匹配不是全部成功，也不表示已删除的行会被回滚。外键级联和触发器可能另外影响关联数据；如当前连接处于显式事务中，提交/回滚沿用该连接原有事务状态。

选择绑定当前页快照，翻页、筛选、排序、刷新及写入后重新读取都会清空，不跨页累积。现有单行删除入口保留。

单元测试验证预览不写入、绑定参数、并发修改、非法/重复行号及一次性令牌；真实 MySQL/PostgreSQL 测试验证批量执行结果。`pnpm test:table-data` 验证桌面全选、确认预览、部分删除提示和刷新后清空选择。
