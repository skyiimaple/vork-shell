# ER 关系图

在 SQL 对象树点击表的「查看结构」，再点击「ER 关系图」。从 SQLite、MySQL 或 PostgreSQL 真实元数据读取字段、主键与外键，不改动数据库结构。

- 小 Schema 初次打开时加载全部表；超过100张时先加载入口表，通过搜索和分页选择范围。
- 每张图最多选择100张表。左侧可以更换 Schema/数据库、搜索名称、翻页和勾选；改变选表后点击「生成关系图」。
- 画布显示字段与类型，PK 为主键。复合外键按数据库中的字段顺序配对，箭头指向被引用表；右侧可以查看完整字段、删除/更新规则和字段对应关系。
- 虚线卡片仅表示外键引用到了未加载的表，不能视为已读取完整字段。点击它后可从右侧加载，或点击「加入关联表」。跨 Schema 的引用也可按此方式加入。
- 拖动表调整布局，拖动空白移动画布，滚轮或按钮缩放。「适应窗口」和「自动布局」可恢复整体视图。
- 默认卡片显示前12个字段，右侧仍可查看所有已读取字段。勾选「完整字段」可在卡片展开；字段数量改变后建议自动布局。
- 「导出 SVG」使用当前布局与字段显示选项，由主进程生成转义后的独立矢量文件。取消保存不会写文件。

图只包含已选表的外键及其引用目标，不推断未选择表的反向引用。当前布局保留在本次面板会话内，不跨重启保存。单次关系图元数据最多4 MiB；超过读取上限会报错或明确提示不完整。读取期间「停止并断开」会断开当前 Query 连接。

`pnpm test:er-diagram` 用临时 SQLite 文件与用户目录验证入口、字段配对、拖动、缩放、未加载关联表、实际 SVG 文件及导出布局。真实 MySQL/PostgreSQL 集成测试位于 `tests/er-diagram.integration.test.ts`，通过专用测试库环境变量开启。纯单元测试还验证分页、字面量搜索、主键顺序、SVG 转义、过期快照与无效坐标。
